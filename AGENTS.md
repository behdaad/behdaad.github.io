# Project instructions

## Git delivery

The repository owner grants standing authorization to commit and push completed, requested changes to `origin/master`. This includes publishing the site's resulting updates. Do not ask for separate permission to push each task.

Before publishing, run the relevant validation, stage only files within the requested scope, and inspect the outgoing commits. Leave unrelated work untouched. If the push would include unrelated commits or requires a force push, stop and explain the issue.

This authorization does not change platform-managed sandbox or approval controls; comply with any enforced tool decision.
